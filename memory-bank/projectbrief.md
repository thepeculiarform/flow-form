# FlowForm Project Brief

## Identity
Python-based architectural design tool for parametric baffle systems in Rhino 3D.

## Purpose
Bridge parametric design with practical architectural implementation for interior baffle systems.

## Core Goals
1. **Parametric Generation**: Centerline-driven baffle systems with automatic constraints
2. **Real-time Control**: Web-based parameter adjustment
3. **Rhino Integration**: Seamless Grasshopper workflow integration
4. **Data Management**: Reliable serialization and synchronization

## Success Criteria
- Seamless baffle generation from centerline inputs
- Real-time parameter control through web interface
- Reliable Rhino ↔ web data synchronization
- Maintainable, extensible architecture
- Production-ready utility for architectural workflows
