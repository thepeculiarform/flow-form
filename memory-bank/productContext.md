# FlowForm Product Context

## Problem
Traditional CAD workflows for architectural baffle systems are time-consuming and lack parametric flexibility for design iteration.

## Solution
Parametric baffle generation with real-time web-based parameter control integrated into Rhino/Grasshopper workflows.

## Target Users
- Architectural designers creating interior baffle systems
- Design technologists implementing parametric workflows
- Rhino/Grasshopper users needing specialized baffle tools

## Core Workflow
1. Define centerline paths in Rhino
2. Adjust parameters through web interface
3. See immediate geometric updates in Rhino
4. Iterate with real-time feedback

## Feature Priorities
**Core**: Parametric generation, length constraints, web control, data sync
**Enhanced**: Material management, hanging points, advanced geometry
**Future**: Structural analysis, collaboration, platform integration
